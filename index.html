Pengaturan Video

Isi parameter utama, lalu tekan Generate.

Setelah Claude terbuka, klik kolom pesan lalu tekan Ctrl + V (Mac: ⌘ + V), kemudian tekan Enter. Prompt tidak dapat dimasukkan langsung ke kolom chat Claude dari halaman HTML ini.
Tool ini tidak memakai API. Claude pribadi pengguna yang menghasilkan naskah dan prompt. Tool tidak menggunakan API. Pengguna tetap mengirim prompt dengan menekan Enter.

Prompt yang Disiapkan

Prompt akan disalin otomatis saat Generate ditekan. Jika clipboard diblokir browser, gunakan tombol Salin Prompt di bawah.

Prompt akan muncul di sini setelah Anda mengisi pengaturan dan menekan Generate.

Master DNA Referensi yang Dikunci

  • Animasi 3D stylized bergaya visual game/CGI edukasi, bukan photorealistic dan bukan 2D.
  • Model dan lingkungan 3D sederhana, bentuk mudah dibaca, warna cerah dan natural, langit biru, awan putih, vegetasi hijau, pencahayaan siang yang terang.
  • Campuran wide/environment shot, medium shot dengan karakter 3D bila relevan, close-up aksi, aerial/oblique view, dan cutaway teknis sesuai topik.
  • Narasi conversational, kalimat mudah dipahami, penjelasan bertahap, sebab-akibat, dan transisi lisan natural.
  • Topik baru mengganti objek dan lingkungan, tetapi tidak mengganti gaya visual, bahasa kamera, atau pola penyampaian referensi.

Format Hasil yang Diminta

Hasil Claude diarahkan agar ringkas, faktual, dan konsisten. Paket SEO YouTube baru muncul setelah scene terakhir, dalam blok siap salin.

  • Naskah VO lengkap dari pembukaan sampai penutup.
  • Scene 1: VO + gambar START FRAME + prompt video. Scene 2 dan seterusnya: VO + gambar END FRAME + prompt video; START FRAME diambil dari frame terakhir video scene sebelumnya.
  • Jika masih ada sisa naskah, berhenti setelah Scene 6 dan tunggu perintah LANJUT.
  • Scene berikutnya meneruskan nomor, timestamp, cerita, dan kontinuitas visual tanpa mengulang scene sebelumnya.
